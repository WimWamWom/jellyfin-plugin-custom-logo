Replacement mode

"Nothing" leaves the served page completely untouched without uninstalling the plugin.

Individual logos

Only used when the mode above is set to "Only the logos I select".
The large logo shown while the web client boots.
The logo in the top bar, including the TV layout.
The logo in the dashboard side drawer.
The icon shown in the browser tab and when pinned to a home screen.

Logo image

A publicly reachable image URL, for example https://example.com/logo.png. Clients load this directly, so it must be reachable from their browsers, not just from the server. If left empty, the default Jellyfin logo is used.
Maximum 2 MB. Uploaded images are embedded directly into the page, which is what removes the extra request that would otherwise cause a flash of the default logo.

Header text

Shown next to the header logo. The browser tab title is not affected by this, that one comes from Dashboard → General → Server name. If left empty, no text is added and the header stays as Jellyfin renders it.

Appearance

A CSS length, for example 2em. A plain number is treated as em. If left empty, the default Jellyfin height is used.
A CSS colour, for example #fff. If left empty, the default Jellyfin colour is used.
A CSS length, for example 1.8em. A plain number is treated as em. Set independently of the logo height; the width follows the text automatically. If left empty, the default Jellyfin size is used.
A CSS font weight. 400 is normal, 600 semi-bold. If left empty, the default Jellyfin weight is used.

Favicon

Off means the favicon uses the logo above.
If left empty, the default Jellyfin favicon is used.
Maximum 2 MB.
Changes apply to the next full page load. Reload the web client (Ctrl+F5 / Cmd+Shift+R) to see them.
